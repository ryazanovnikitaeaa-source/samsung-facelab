# Материалы к проекту

- `FaceLab.pptx` — 11 редактируемых слайдов с заметками докладчика и источниками. Текущий статус: приложение работает, независимый пользовательский набор ещё не собран. Перед итоговой защитой нужно указать автора и группу, добавить фактический состав набора и результаты своего теста.
- `FaceLab-demo.webm` — запись реального приложения, 29.68 секунды, 1600×900, без звука, около 2.3 МБ. Открытые технические портреты. Показывает регистрацию, узнавание изменённого снимка, неизвестный портрет и несколько лиц. Не является независимым экспериментом по точности.

Происхождение данных: `../docs/sources.md`. Протокол личного эксперимента: `../docs/experiments.md`. Сценарий защиты: `../docs/defense.md`.
