# Улучшения FaceLab, 22 октября 2026

Пользователь согласовал: контроль качества снимков, сравнение порогов и отчёт для защиты. Реализация локальная, без новых платных сервисов, без обучения весов моделей и без использования личных фото в автоматической проверке изменений.

## Решения
- Качество оценивается эвристически по размеру области лица, резкости и яркости. Замечания предупреждают, но не блокируют регистрацию. Отдельная кнопка предварительной проверки выполняет только обнаружение и оценку изображения без сравнения личности. В распознавании показываются рекомендации для найденных областей.
- Для валидации сохраняется лучший кандидат до применения порога. На этих числовых результатах строятся кривые без повторного запуска модели. Валидация и итоговый тест не смешиваются в одной проверке. Старые результаты сохраняются, но сравнение порогов без исходного кандидата недоступно.
- Рекомендация порога допускается только в валидации, при наличии известных и неизвестных примеров. Критерий: среднее между долей правильно определённых известных и долей верных отказов неизвестным, затем меньше ложных узнаваний, затем близость к исходному порогу. Сетка 0.2–0.8, шаг 0.01, дополнительно 0.363 и текущий порог. Это эмпирический выбор, а не обещание качества на других данных.
- Отчёт HTML пригоден для печати/PDF средствами браузера, содержит состав выборки, модели, порог, метрики, кривые для валидации, случаи ошибок и ограничения. По умолчанию участники и имена файлов обезличены. JSON/CSV продолжают работать.
- Имена людей, база, личные фото и реальные пользовательские отчёты не читаются при разработке, не очищаются и не публикуются. Тесты используют искусственные данные и открытые технические примеры, браузер запускается с отдельной тестовой базой.
