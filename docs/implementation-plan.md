# FaceLab Implementation Plan

**Goal:** реализовать согласованное в design.md приложение и подготовить проверяемые материалы защиты.

**Architecture:** локальный FastAPI, статический русский интерфейс, SQLite, CPU-модели OpenCV. Извлечение признаков отделено от хранения и принятия решения.

**Tech Stack:** Python 3.12, OpenCV, NumPy, Pillow, FastAPI, Uvicorn, SQLite, pytest, Playwright для проверки UI.

## Constraints
Локальные данные; отсутствие выдуманных результатов; реальные модели; неизвестные лица; поддержка Windows; никаких обязательных платных сервисов.

## Verification commands
`python -m pytest -q` — вся прикладная логика и API.
`python scripts/smoke_models.py` — реальные YuNet/SFace.
`python run.py --no-browser` — локальный сервис для браузерной проверки.
`git status --short` и `git ls-files` — проверка состава публикуемых файлов.
