# Выбор лица при регистрации

Пользователь просит устранить отказ регистрации снимка, на котором помимо основного портрета детектор находит лицо на фоне. Проверка обнаружения подтвердила две области; возраст и сходство при регистрации не проверяются. Снимок проверялся только через inspect, без признаков личности и без записи в базу.

Решение: при нескольких обнаруженных лицах показывать нумерованные рамки и требовать явного выбора пользователя. Автоматически выбирать самое крупное лицо нельзя: это может сохранить чужой эталон. Отклонение таких снимков сохраняется для клиентов без выбора. Основная база, фото и настройки распознавания не изменяются автоматически.

- [x] FaceEngine.process(data, face_index=None) извлекает признаки только выбранного лица, inspect остаётся без признаков. FaceService.enroll(name, files, face_choices=None) принимает список индексов или null по порядку файлов. POST /api/people принимает JSON face_choices; неверные значения отклоняются.
- [x] Предпросмотр /api/quality возвращает изображение и размеры для нескольких лиц. UI автоматически проверяет фото перед сохранением, показывает отдельные рамки/кнопки выбора. Изменение файлов сбрасывает выбор; старый ответ игнорируется.
- [x] Браузерная проверка на искусственных изображениях с временной базой: выбор, сохранение, нулевой результат, сброс выбора и устаревший ответ. Проверить мобильную вёрстку.
