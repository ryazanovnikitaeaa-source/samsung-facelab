# Публикация исходного кода

Репозиторий проекта: https://github.com/ryazanovnikitaeaa-source/samsung-facelab

Для подключения локальной копии к репозиторию:
```powershell
git remote add origin https://github.com/ryazanovnikitaeaa-source/samsung-facelab.git
git push -u origin main
```

Перед отправкой проверьте `git ls-files`: в списке не должно быть `data/`, `tmp/`, `.venv/`, фотографий участников или ONNX-файлов. Скриншоты и видео демонстрации используют открытые технические примеры с атрибуцией в `sources.md`. Если материалы будут заменены на личные снимки, вопрос их публикации решается отдельно.

Установка на другом компьютере выполняется через `setup.bat`, а не копированием `.venv`. При сдаче укажите ссылку на репозиторий и версию/коммит, по которому выполнялась защита.
