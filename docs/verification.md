# Проверка реализации

Дата: 19 октября 2026 года. Windows x64, Python 3.12.14, OpenCV 5.0.0.

## Автотесты
`python -m pytest -q`: **24 passed**, 8.49 секунды в заключительном прогоне. Одна deprecation-подсказка Starlette относится к тестовому клиенту httpx и не является ошибкой приложения.

Проверены порог и отказ, нормирование и пустая база, выбор эталона, отдельные знаменатели метрик, регистрация/распознавание/удаление, атомарность регистрации, повторы имён и снимков, повреждённые файлы, число лиц, защита от эталонов в тесте, неизменность порога, сброс проверки при изменении базы, API и отклонение внешнего Host/Origin. Реальная загрузка ONNX проверена отдельным тестом, включая путь с кириллицей.

## Настоящие модели
`scripts/smoke_models.py`: пройдены четыре технических сценария: изменённая копия эталона, другой портрет, два лица в кадре, пустой кадр. Исходные портреты открытые. Это не независимый тест точности.

Контрольные суммы обеих моделей совпали с официальными Git LFS-указателями. Особенность чтения кириллицы OpenCV устранена загрузкой моделей из буферов Python.

## Браузер
Проверены реальная регистрация, неизвестное лицо при пустой базе, групповой кадр с известным и неизвестным лицом, отклонение эталона при оценке, два технических случая оценки, скачивание PNG и JSON, три вкладки на узком экране без горизонтального выхода страницы. HTTP 400 при намеренном использовании эталона ожидаем.

Устаревший ответ после смены выбранного снимка воспроизведён и устранён счётчиком версии. Повторный браузерный сценарий подтвердил, что ответ старого запроса не отображается.

## Материалы
Все 11 слайдов просмотрены по отрендеренным изображениям. Проверка структуры PPTX, геометрии, шрифтов и повторного импорта завершилась без замечаний. Презентация не проверялась непосредственно в Microsoft PowerPoint. Видеофайл декодируется, имеет длительность 29.68 секунды и размер меньше 100 МБ. Кадр записи просмотрен.

## Требует участия студента
Независимый набор личных фотографий, измерение итогового качества, добавление фактических результатов на слайды, автор/группа и подготовка ответов на защите. Эти действия не заменяются техническими примерами.

## Исправление обнаружения крупных лиц, 22 октября 2026 года
Если исходный размер не дал обнаружений, добавлен повторный проход YuNet на уменьшенных копиях с длинной стороной 640 и 320 пикселей. Порог обнаружения не снижен. Рамки и пять опорных точек пересчитываются к исходным координатам с отдельными коэффициентами по X и Y.

Четыре новые проверки покрывают повторный проход, сохранение результата первого прохода, отсутствие увеличения маленьких изображений и корректность координат после округления. Полный набор: **28 passed**, 8.61 секунды, одна прежняя deprecation-подсказка тестового клиента. Технический smoke-test на открытых примерах также пройден. На локальных пользовательских снимках проверялось только обнаружение лиц, без извлечения признаков, сопоставления личности или изменения базы.

## Качество снимков, пороги и печатный отчёт, версия 1.1.0
22 октября 2026 года: **49 passed**, 9.52 секунды, одна прежняя deprecation-подсказка. Новые проверки покрывают эвристики качества, отсутствие извлечения признаков в предварительной проверке, сохранение с предупреждениями, пересчёт кандидатов при разных порогах, разделение валидации и теста, старые результаты, экранирование автора и обезличивание HTML, API и версии снимков отчёта. Технические сценарии реальных моделей на открытых примерах повторно пройдены.

Браузерные проверки выполнены на отдельном порту 8766 с временной базой и искусственными изображениями/векторами. Проверены предварительные рекомендации, регистрация, известный и неизвестный случаи, график из 62 точек, рекомендация и её применение, итоговый режим без подбора, блокировка режима и порога, JSON/CSV, обезличенный HTML. Задержанный GET с двумя случаями после сброса не возвращает старые строки; во время evaluate кнопка сброса недоступна. Все три вкладки помещаются по ширине при 390 пикселях. Снимки интерфейса и отчёта просмотрены. Обзор кода выявил два дефекта; исправления проверены повторно, существенных замечаний не осталось.

Основная база и личные снимки в этой проверке не использовались. Числа из искусственных сценариев не являются оценкой точности проекта.

## Ручной выбор лица при регистрации, версия 1.1.1
22 октября 2026 года: **60 passed**, 12.00 секунды, одна прежняя deprecation-подсказка тестового клиента. Новые тесты проверяют извлечение признаков только выбранной области, сохранение выбранного искусственного вектора, некорректные значения/количество индексов и JSON, предварительный просмотр без сохранения. Строгий отказ при нескольких лицах без явного выбора и атомарность сохранены.

На отдельном сервере с временной базой и искусственными изображениями проверены автоматический предпросмотр, отсутствие POST до выбора, выбор второй области и сохранение двух эталонов одной записью, отказ при нуле лиц, сброс выбора при замене файлов, игнорирование задержанного предпросмотра, мобильный экран 390 пикселей. Во время задержанного POST имя, файлы, выбор и закрытие блокируются, после ответа доступность восстанавливается. Обзор кода выявил гонку выбора во время сохранения; она воспроизведена, исправлена и повторно проверена. Синтаксис JS и технические сценарии реальных моделей пройдены.

На одном предоставленном пользователем изображении выполнено только обнаружение: найдены две области, включая лицо на фоне. Признаки не извлекались, сопоставление личности не выполнялось. Пользовательская база не читалась и не заполнялась при проверках.
