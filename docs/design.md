# FaceLab — согласованный проект Samsung

Основание: пользователь выбрал тему № 2 «Распознавание лиц», подтвердил использование предобученной модели, локального интерфейса в браузере, предоставление фотографий и разрешил реализацию сообщением «Готов».

## Результат
Локальное приложение на Python: регистрация человека по нескольким фотографиям, распознавание нескольких лиц на новом снимке, отказ «Неизвестный», удаление записей, независимая проверка качества и экспорт отчёта. Русский интерфейс. Бесплатное выполнение на CPU. Модели YuNet и SFace из OpenCV Zoo; используем условия лицензий конкретных моделей.

## Архитектура
- FastAPI обслуживает HTML/CSS/JS и API на 127.0.0.1:8765.
- YuNet находит лица и опорные точки; SFace выравнивает лицо и извлекает 128 признаков.
- Нормированные признаки фотографий хранятся в SQLite. Для каждого человека выбирается максимальное косинусное сходство с эталонами. Порог по умолчанию 0.363 — исходная точка из документации OpenCV, не гарантия точности и не вероятность.
- В исходники и Git не попадают пользовательская база, портреты, тестовые снимки, результаты распознавания и загруженные ONNX.
- Регистрация принимает одно обнаруженное лицо или одно явно выбранное пользователем лицо из нескольких. Предпросмотр показывает нумерованные рамки без извлечения признаков. При сохранении извлекаются признаки только выбранной области. Операция атомарна: ошибочный снимок отменяет регистрацию целиком. Повтор имени отклоняется. Повтор эталонного файла внутри регистрации отклоняется.
- Приложение хранит только признаки и небольшую очищенную от метаданных миниатюру. Проверяемые фотографии обрабатываются в памяти.
- Оценка качества: пользователь выбирает истинное имя или «Неизвестный», загружает независимые одиночные портреты. Повторные фото и эталонные файлы отклоняются; иной кадр того же человека должен быть реально независимым. Метрики: доля верных ответов, ошибки узнавания, ложные допуски, ложные отказы, время обработки, таблица случаев. Отдельные знаменатели для известных и неизвестных.
- Тесты с подставным извлекателем проверяют прикладную логику; отдельная интеграционная проверка запускает настоящие модели на открытом техническом примере. Она не заменяет проверку на пользовательском наборе.

## Интерфейс
Три раздела: распознавание, база людей, проверка качества. Явные состояния загрузки, ошибок, отсутствия лиц, пустой базы и отсутствующих моделей. Слайдер порога, результат с рамками и именами, скачивание размеченного изображения. Таблица качества и экспорт JSON/CSV. Значение сходства не называется процентом уверенности.

## Комплект к защите
Код и инструкция для GitHub, описание архитектуры и источников, презентация с честным статусом экспериментов, сценарий защиты и демонстрации. Итоговые метрики и персональное видео заполняются после получения пользовательских фотографий. Чужие имена, авторство, успешные эксперименты и точность не выдумываются.

## Проверка и границы
Автотесты на неизвестные лица, порог, повреждённые файлы, отсутствие/несколько лиц при регистрации, удаление, повтор данных, метрики; запуск реальных ONNX; проверка браузера и узкого экрана. На старте никаких аккаунтов, камер, внешних вызовов и автоматического размещения персональных фото.
